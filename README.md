# Daria Soldatova — Portfolio

Personal site for Daria Soldatova, mid-level UI/UX designer and researcher. Built with **Next.js 16** (App Router), **React 19**, and **Tailwind CSS 4**.

Includes SpankPls case studies, a Behance freelance gallery, SextPanther bonus work, About/Approach copy, and `ButtonGlowSync` hover glow.

## Local development

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

## Deploy on Vercel

1. Import this GitHub repo in [Vercel](https://vercel.com/new).
2. Framework Preset: **Next.js** (leave build/output defaults).
3. Deploy.

Expected live URL: `https://<project-name>.vercel.app` (plus any custom domain you attach).
